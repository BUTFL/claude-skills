## One-line install (recommended)

> This is a **public** repo — install without cloning:

```bash
curl -fsSL https://raw.githubusercontent.com/BUTFL/claude-skills/main/install.sh | bash -s -- --target both
```

Or clone first:

```bash
git clone https://github.com/BUTFL/claude-skills.git
cd claude-skills
./install.sh --target both
```

## Updating skills

```bash
cd claude-skills
git pull
./install.sh --target both --force
```

## Sync back (local → repo) (upload.sh)

Collect local skills back into the repo (optionally commit & push):

```bash
./upload.sh --from claude          # collect from ~/.claude/skills
./upload.sh --pick                 # interactively choose skills (language first)
./upload.sh --push                 # push directly to main
./upload.sh --pr                   # open a Pull Request (bilingual body)
```

With `--push` / `--pr`, the **commit message, terminal output and PR body list every added/updated skill in both Chinese and English**, and both READMEs are synced automatically.

## Before uploading (mandatory)

| Step | What to do |
|---|---|
| ① Format | Follow [CONTRIBUTING.en.md](CONTRIBUTING.en.md) |
| ② Validation green | `./validate.sh` must print `All checks passed` |
| ③ Code review | AI reviews structure, bilingual descriptions and security |
| ④ Submit | `./upload.sh --push` or `--pr` (validation runs automatically and **blocks** on failure) |

## Sync with AI (skill-sync)

The repo ships `skills/skill-sync`. Once installed, just tell the AI:

> sync my skills / update skills / restore skills

It will pull this repo and install everything for you.

## Notes

| Flag | Effect |
|---|---|
| `--target claude` | Install into `~/.claude/skills` (default) |
| `--target codebuddy` | Install into `~/.codebuddy/skills` |
| `--target both` | Install into both |
| `--force` | Overwrite existing skills (skipped by default) |

- Existing skills are **skipped** by default; your other local skills are never deleted.
- **Restart** the tool after installing so new skills show up in the list.
- One directory per skill (containing `SKILL.md`), all under `skills/`.
- Both READMEs are generated by `scripts/gen-docs.py`; `upload.sh` syncs them before committing. Uncategorized skills land in the "Other" section automatically.
- Skills you do not want to upload go into your local `.skillignore` (see [CONTRIBUTING.en.md](CONTRIBUTING.en.md)).
- The repo itself (scripts and docs) is **MIT** licensed; some skills come from public marketplaces and keep their original licenses.
